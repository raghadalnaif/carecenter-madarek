# نشر خادم مدارك (منصة متعددة المدارس)

نظام التخزين: خادم Node.js صغير يحفظ بيانات كل مدرسة معزولة تماماً في
SQLite على نفس السيرفر، ويزامنها لحظياً بين الأجهزة عبر SSE. أي عدد من
المدارس يمكنه استخدام نفس الرابط — كل مدرسة تسجّل حسابها الخاص (اسم
مستخدم وكلمة مرور مستقلين) ولا ترى بيانات مدرسة أخرى إطلاقاً.

## الخطوات (على السيرفر، كـ root)

### 1) اسحب آخر تحديث
```
cd /var/www/madarek && git pull
```

### 2) شغّل سكربت الإعداد (مرة واحدة، أو أعد تشغيله بأمان لتحديث النسخة)
```
bash /var/www/madarek/deploy/setup.sh
```
يثبّت Node، اعتماديات الخادم، يولّد **مفتاح مزوّد الخدمة** (PLATFORM_TOKEN)،
يشغّل الخدمة، ويجدول نسخة احتياطية يومية. سيطبع `PLATFORM_TOKEN=...` —
**احفظي هذا المفتاح في مكان آمن**، فهو مفتاح لوحة تحكم مزوّد الخدمة
(إدارة كل المدارس) ولا يمكن استرجاعه من الواجهة لاحقاً.

### 3) أضف مسار /api إلى nginx
عدّل `/etc/nginx/sites-available/madarek` وأضف داخل **كل** كتلة `server`
(منفذ 80 ومنفذ 443 الذي أضافه certbot) الكتلتين التاليتين قبل `location / {`:
```
location /api/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_read_timeout 1h;
}
location = /api/stream {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Connection '';
    proxy_buffering off;
    proxy_read_timeout 24h;
}
```
ثم:
```
nginx -t && systemctl reload nginx
```

### 4) أول تشغيل بعد الترحيل من نظام المدرسة الواحدة
إذا كان لديك بيانات سابقة (نظام "مدرسة واحدة")، عند أول تشغيل للخادم
الجديد يُنشئ تلقائياً **مدرسة افتراضية** تحتوي كل بياناتك القديمة، ويطبع
اسم المستخدم وكلمة المرور المؤقتة في سجل الخدمة، ويحفظها أيضاً في:
```
/var/www/madarek/server/default-tenant-credentials.txt
```
اعرضيها بـ:
```
journalctl -u madarek-api -n 30 | grep -A3 "تم ترحيل"
```
سجّلي بها الدخول من صفحة الموقع (تسجيل دخول المدرسة)، ثم **غيّري كلمة
المرور فوراً** من لوحة مزوّد الخدمة (الخطوة التالية).

### 5) إدارة المدارس من لوحة مزوّد الخدمة
افتحي `https://kidsenses.today/#provider` وأدخلي مفتاح مزوّد الخدمة
(PLATFORM_TOKEN من الخطوة 2). من هناك:
- **إضافة مدرسة يدوياً** (اسم مستخدم/كلمة مرور تُنشئينها أنتِ)، أو
- **تفعيل مدرسة سجّلت نفسها** من صفحة الموقع (تظهر بحالة "قيد المراجعة")
- لكل مدرسة: نوع العضوية (روضة / حضانة - دار ضيافة / مدرسة بكل مراحلها)،
  ومدة الاشتراك (الفصل الأول/الثاني/العام كاملاً/أشهر محددة) وتواريخه،
  وحالة الحساب (نشطة/قيد المراجعة/موقوفة).
- عند إيقاف مدرسة أو انتهاء تاريخ اشتراكها، تُمنع من الدخول لبياناتها
  تلقائياً حتى تُفعَّل مجدداً.

⚠️ لوحة مزوّد الخدمة عامة الوصول (على نفس رابط الموقع) لكنها محمية
بالمفتاح السرّي فقط — لا تشاركي هذا الرابط أو المفتاح مع أحد غير موثوق.

## التحقق
- `curl -s http://127.0.0.1:3001/api/health` → `{"ok":true,"tenants":N,...}`.
- `systemctl status madarek-api` → active (running).
- النسخ الاحتياطي: `/var/backups/madarek/`.

## أوامر مفيدة
```
systemctl restart madarek-api     # إعادة تشغيل الخدمة
journalctl -u madarek-api -n 50   # سجل الخدمة
/usr/local/bin/madarek-backup.sh  # نسخة احتياطية فورية
```
